# Sprite credits

Riolu (#447) game sprites are served locally from the PokeAPI sprite collection:
https://github.com/PokeAPI/sprites

Animated: `sprites/pokemon/versions/generation-v/black-white/animated/447.gif`.
Static reduced-motion alternative: `sprites/pokemon/447.png`.

The Rotom Dex SVG is an original pixel-style vector interpretation created for this portfolio.

Pokémon characters and game sprites belong to their respective rights holders (Nintendo / Creatures / GAME FREAK). PokeAPI is the distribution source, not the character rights holder. This portfolio is an independent fan project with no official affiliation.
